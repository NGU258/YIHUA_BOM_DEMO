# 关于BOM树形结构的两种设计方案
## 方案一
* 子节点的一个字段存BOM根节点ID 另一个字段存它父节点的ID
> 优点： 查询高效 语义明确
> 缺点: 多加了一个字段
> ![img_3.png](/笔记图片/img_3.png)

## 方案二
* BOM根节点ID跟父节点ID都同时存到子节点的一个字段中
> 优点: 少加了一个字段
> 缺点: 需要递归查询  查询效率比较慢 语义不是很明确
> ![img_4.png](/笔记图片/img_4.png)
